# GrindMode 💼

> The #1 productivity app for people who use productivity apps instead of doing work.

## Features

- **Productivity Score Calculator** — Measures your output in a completely made-up unit
- **AI-Powered Wisdom™** — Random advice dispensed with confidence
- **Focus Timer** — A Pomodoro timer that will definitely help
- **Cloud Sync** — Saves to localStorage and calls it the cloud

## Getting Started

Open `index.html` in a browser. No build step. We move fast here.
